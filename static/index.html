Each point is one positive earnings surprise. Horizontal axis is Yahoo’s surprise percentage; vertical axis is the 2-day close-to-close return.

How this is measured

  1. Load earnings dates with Ticker.get_earnings_dates().
  2. Download the complete daily close history with Ticker.history(period="max").
  3. For every three consecutive sessions (Day 1, Day 2, Day 3), compute CloseDay3 / CloseDay1 − 1, indexed on Day 2.
  4. Keep prints with a reported EPS and Surprise(%) > 0, take the median 2-day return, then correlate that return with surprise magnitude.
